# Color Retouch

Complemento de Blender (4.2 – 5.x) para retocar los colores de una pieza por caras, todo en modo Objeto:
pincel, cubo de relleno y cuentagotas, paleta de colores de la pieza y colores nuevos.
Pensado para dejar bonitas las piezas antes de grabar el vídeo con **Showcase** o separar colores con **Color Splitter**.

Instrucciones: [color_retouch/LEEME.md](color_retouch/LEEME.md).

Instalar: `python crear_zip.py` → Blender → Preferencias → Complementos → Instalar desde disco → `dist/color_retouch-1.1.0.zip`.
